Project Manager needs an OpenAI key

It reads the replies you capture using your own OpenAI account, about 2 cents per captured reply.

  1. Sign in or create an account at platform.openai.com. This is separate from a ChatGPT subscription, which doesn't include it.
  2. Add credit on the billing page. $5 is plenty to start. OpenAI's setup has auto-reload on by default, which buys more credit automatically when your balance runs low. Switch it off at the review step if you don't want a second charge.
  3. Create a secret key on the API keys page and copy it.
  4. Paste it here and test it.

    Stored only in this browser. Sent only to api.openai.com.

You're set. Open a conversation on chatgpt.com or claude.ai and press Capture round under the latest reply. A round is one reply you capture, checked against your goal and your earlier rounds. Press it when a piece of work is done or a decision is made, not under every reply.
